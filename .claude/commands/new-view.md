# /new-view

Translate the operator's question into a read-only query against the existing records. Inspect the schema and existing views.json. If a new database view is needed, add it in a numbered migration, revoke public access and include a meaningful smoke assertion. Add the display to views.json using the shared renderer and brand.json. Run npm test and npm run view. Open the resulting HTML and check the values against the CLI. Do not add a web app or change records. State the time of the snapshot.
