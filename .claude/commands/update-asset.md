# /update-asset

Read assets first. Retired equipment needs disposal evidence. Custody is a record, not proof of encryption or safe disposal.

Run:

```bash
npm run service -- update-asset --asset=A-1 --custodian=Casey --review-on=2027-01-01 --actor=Casey
```

Replace example facts and dates with confirmed values. Append --json for structured output. Record the real operator in --actor. Review the returned record before reporting success. Do not invent an event or send anything.
